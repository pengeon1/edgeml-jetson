### [STEP 3] Ungraceful Hardware Power-Cut / SysRq Reset (1 minute)
# Presenters: Ankush R & Mahalis Rayhan
# Run on a SECOND LAPTOP terminal while Step 2 dashboard is streaming:
ssh nano-usb "echo 1 > /proc/sys/kernel/sysrq; echo b > /proc/sysrq-trigger"

# (SSH terminates instantly. Count out loud: 1... 2... 3... 4 seconds!)

# Reconnect and prove EXT4 filesystem integrity & zero journal corruption:
ssh nano-usb "mount | grep ' on / '; dmesg | grep -i 'EXT4-fs'"

# Key outputs to show Dr. Raghavan:
# - "/dev/mmcblk0p1 on / type ext4 (ro,relatime,data=ordered)"
# - ZERO corruption or recovery errors!
# - Check http://localhost:8080 in browser: detection stream automatically resumed!


--------------------------------------------------------------------------------
2. BACKUP & DEEP-DIVE COMMANDS (If Dr. Raghavan Asks Questions)
--------------------------------------------------------------------------------

# Q: "Show me the trimmed kernel size and version"
ssh nano-usb "uname -r; ls -lh /boot/Image"
# Result: Linux 4.9.337, 28.5 MB kernel image (26% smaller than 38.5 MB stock).

# Q: "How much RAM is the OS actually using at idle?"
ssh nano-usb "free -m"
# Result: ~217 MB in use, ~3.7 GB free for deep learning workloads (68% less than stock's 670 MB).

# Q: "Can you prove the root filesystem is really immutable / tamper-proof?"
ssh nano-usb "touch /etc/hacked.txt"
# Result: touch: /etc/hacked.txt: Read-only file system

# Q: "Show the systemd security sandboxing directives for the detector"
ssh nano-usb "systemctl cat edgeml-detector.service"
# Result: Shows User=edgeml, ProtectSystem=strict, NoNewPrivileges=true, DeviceAllow=...

# Q: "Show the systemd-analyze security score comparison"
ssh nano-usb "systemd-analyze security edgeml-detector.service"
# Result: Overall exposure level: 3.2 OK.

# Q: "Can you switch power modes dynamically?"
# Switch to 5W mode:
ssh nano-usb "nvpmodel -m 1"
# Switch back to 10W MAXN mode:
ssh nano-usb "nvpmodel -m 0"

# Q: "Check live temperatures, clocks, and power rails"
ssh nano-usb "tegrastats --interval 1000"
# (Press Ctrl+C to exit)

# Q: "Inspect active network ports on the board"
ssh nano-usb "netstat -tulpn"
# Result: Only SSH (port 22) is listening externally.

# Q: "Check detector service logs in real time"
ssh nano-usb "journalctl -u edgeml-detector -f"
# Result: Prints continuous pipeline logs: fps=20.0 infer=48ms pre=11ms mqtt=ok.
